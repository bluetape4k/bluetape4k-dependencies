# 2026-05-20 — README 개요 시각 요소 배치

## 배경

README 다이어그램과 차트는 장식용으로 생성한 자산이 아니라 소스에 근거한
문서로 다뤄야 한다. 이번 작업에서는 2026년 참고 문서와 공용 README 다이어그램
스타일 가이드를 사용했지만, 모듈 이름과 그룹화의 기준은 소스 코드와 빌드 구성을
그대로 유지했다.

## 결정

루트 README에 영문 전용 SVG+PNG 개요 시각 자료를 추가하고, 개요 다이어그램을
설치, 사용법 또는 빌드 안내보다 앞에 배치한다. 기존 Architecture/Diagram 섹션이
사용 예제 뒤에 붙어 있으면 위쪽으로 이동한다.

## 결과

`bluetape4k-dependencies` 루트 README에 개요 다이어그램과 모듈 구성 차트가
추가되었고, README 시각 자료의 배치는 개요 우선 규칙을 따른다. 생성된 레이블에는
이미지 내부의 현지화 텍스트를 사용하지 않는다.

## 검증

- 생성된 SVG 파일을 `xmllint --noout`으로 파싱했다.
- 생성된 PNG 파일을 `rsvg-convert`로 렌더링했다.
- 워크스페이스 README 이미지 링크 검사에서 누락된 로컬 이미지가 없었다.
- 워크스페이스 Architecture/Diagram 순서 검사에서 Installation, Usage,
  Examples 또는 Build 제목 뒤에 남은 섹션이 없었다.
- 생성된 루트 개요 SVG 텍스트에 비 ASCII 문자가 없었다.

## 향후 참고

README 파일 끝에 아키텍처 다이어그램을 덧붙이지 않는다. 개요 또는 아키텍처
다이어그램은 위쪽에 배치하고, 클래스·시퀀스·ERD·흐름 다이어그램은 설명하려는
섹션 옆에 둔다.

루트 개요 다이어그램과 구성 차트는 BOM이 있으면 BOM을 첫 번째에 배치하고,
Examples 또는 Additional examples가 있으면 마지막에 배치한다. 중간 그룹은 저장소별
README에서 알파벳순 그룹화를 요구하지 않는 한 소스를 기준으로 정한 방향 순서를
유지한다.
